# axon

the bundle of all [[cyberlinks]] between two [[particles]], across every [[neuron]] and all time — itself a [[particle]] (axiom A6), so it is rankable and linkable like any node.

the [[cybergraph]] holds the cyberlink record from which axons emerge; they are never created directly. weighting, [[focus]] flow, and effective adjacency are defined by [[tru]] — see [[axon]] for the full specification.
